Sistema de Predicción de Diabetes

Sobre el proyecto

Este proyecto es un modelo avanzado de Machine Learning en el que se aplica regresión lineal, regresión logística y redes neuronales para predecir la probabilidad de que un paciente desarrolle diabetes en el futuro. Procesando grandes volúmenes de datos históricos clínicos, el pipeline identifica las variables más determinantes, elimina outliers y normaliza la información para alimentar y entrenar los modelos con la máxima precisión posible.

Se utiliza la Ciencia de Datos y la ingeniería Backend de nuevo, se procesan grandes volúmenes de datos históricos de otros pacientes, se reconocen las variables más determinantes, se eliminan los outliers, y se normalizan los datos para entrenar los modelos correspondientes.

Características principales

  • Análisis de correlación: Identificación de las variables más determinantes mediante mapas de calor frente al diagnóstico de diabetes.
  • Preprocesamiento de datos: Reducción de dimensionalidad (eliminación de variables no relevantes) y normalización del dataset.
  • Modelado con Redes Neuronales: Diseño, entrenamiento y validación del algoritmo para lograr predicciones precisas basadas en los datos clínicos.

Mi aportación

Diseñé y desarrollé el flujo completo del modelo partiendo desde la exploración de los datos. Implementé los scripts para la selección de variables dependientes, la limpieza profunda del dataset y el entrenamiento final de la red. Los resultados obtenidos, tras entrenar el modelo con 70.000 registros durante 200 iteraciones, demuestran un alto rendimiento: un Error Medio Absoluto (MAE) de tan solo 1.34, un Error Cuadrático Medio (MSE) de 2.96 y un Error Relativo Medio del 4.92%.
